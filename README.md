## 🌌 About this project
BlackHoleTrash replaces your standard Windows Recycle Bin with a visual simulation of a black hole. When you move files into this icon, the software triggers a gravitational lensing effect. Files appear to warp and vanish past the event horizon. This tool functions like a normal trash bin but updates your desktop with high-quality graphical performance. It provides a unique way to manage file deletion on your Windows workstation.

## ⚙️ How to use
Once the setup finishes, the black hole icon appears on your desktop. You can use it just like your old Recycle Bin. 

* **To delete a file:** Click and drag any file from your folders onto the BlackHoleTrash icon.
* **To see the effect:** Watch the icon as the object shrinks and warps toward the center.
* **To restore files:** Double-click the black hole icon to open the storage window. Right-click any file inside and select Restore to return it to the original location.
* **To empty the trash:** Right-click the desktop icon and select Empty Black Hole to remove all files permanently.

## 🛠️ Customizing settings
You can change the visual behavior of the black hole. Right-click the icon and select Settings to open the menu.

* **Gravity Strength:** Move the slider to change how fast files shrink when you drop them.
* **Event Horizon Color:** Choose a color for the glow around the edge of the hole.
* **Animation Speed:** Select how fast the lensing effect plays on your screen.
* **Startup Behavior:** Decide if you want the app to open automatically when you turn on your computer.

## 🛡️ Safety and security
This program interacts with your Windows file system to move data to a hidden folder. It respects your privacy. The software does not send your data to external servers. All file operations happen locally on your hard drive. The gravitational lensing uses local GPU power to create the visual effect without tracking your user habits.

## ❓ Frequently asked questions
* **Does this replace my Recycle Bin?**
Yes, it acts as a replacement. You can hide the original icon by checking your desktop icon settings in Windows.
* **Can I still use keyboard shortcuts?**
Yes. Selecting a file and pressing the Delete key will send the file to your BlackHoleTrash folder.
* **What happens if I delete large folders?**
The visual effect scales to fit the file size. Large files result in a stronger distortion effect.
* **Does it use much battery?**
The animation only runs when you move a file. During idle times, the application uses minimal system resources.
* **Can I uninstall the software later?**
You can remove the program at any time through the Windows Add or Remove Programs menu.

## 🔍 Troubleshooting
If the program does not appear on your desktop after installation, restart your computer. If the animation lags, check your graphics card drivers. Ensure your drivers are up to date through the manufacturer website. If the icon disappears, right-click your desktop, select View, and ensure Show Desktop Icons is checked.
